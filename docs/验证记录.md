### 逻辑与界面测试（4 项逻辑 + 2 项 Android 界面）

1. 购物车重复去重；空购物车不能生成订单。
2. 下单保存双宠物及地址快照、计算 310 美元总额、清空购物车。
3. 本地恢复引导/登录、收藏、发布、分会话消息与订单。
4. 非法 JSON 不导致启动崩溃。
5. 320 × 640 小屏引导可滚动完成。
6. 375 × 812 屏幕上的演示入口、底部导航和无结果搜索。

### 模拟器流程

- 欢迎 → 3 页引导 → 登录；注册空字段校验；找回密码页面。
- 探索页排序、价格筛选后只显示符合条件的宠物。
- 详情页收藏、加入购物车、双宠物合计。
- 新建地址、切换为新增地址、新建样例支付方式。
- 确认金额 → 提交订单 → 成功 → 订单列表 → 历史详情。
- 进入会话、发送文本、检查对应会话中的持久化内容。
- 发布页 → Explorer → Album → 选择原稿图片 → 日期和表单填写 → 发布。
- 个人资料编辑、重建状态检查保存内容、首页检查新发布宠物。
- 每个截图点检查 Flutter 异常，截图前收起键盘并移除提示条。

### 视觉检查与修正

检查了全界面概览与首页、详情、引导、登录、聊天、确认订单、个人资料及发布结果等原尺寸截图。修复了小屏首页标题行溢出、相册条目的 Material 点击反馈问题，以及软件渲染下背景渐变的细线问题。截图与原稿分开存放，便于核对。

APK 为本地演示签名，生产入口为 `lib/main.dart`，不含集成测试入口。交付包和 SHA-256 记录位于 `dist/`。安装启动验证截图在 `verification/release-home.png`。

## 尚未验证或未接入

Windows 的 `flutter_tester` 在带图片的界面测试中出现过原生进程退出。界面测试因此与完整流程一起放到 Android 模拟器执行，桌面测试仅负责业务逻辑，避免把测试宿主的问题当作业务断言结果。

- Windows 环境未进行 iOS/Xcode 构建和运行验证。
- Web 源码已生成，未执行浏览器端完整验收。
- 系统相册/相机使用官方插件并配置权限说明；自动化发布流程使用内置样例图片，未覆盖真实设备权限交互。
- 真实认证、短信/邮件、消息投递、语音/视频、地图、付款及物流服务未接入；这些边界已在界面反馈与项目说明中标明。
